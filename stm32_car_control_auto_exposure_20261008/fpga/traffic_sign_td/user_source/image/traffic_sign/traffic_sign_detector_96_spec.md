# traffic_sign_detector_96

## 功能

模块在 96 位四像素 RGB 流中检测蓝色路牌候选框。当前帧累计蓝色像素的单一外接框；下一帧在该区域内统计白色像素左右分布，并输出 `L`、`R` 或 `?`。

输入依次经过四像素字寄存器级和颜色特征寄存器级。帧尾白色像素总数再进入结果寄存器级后完成分类。`I_tuser`、`I_tlast` 与像素数据同步延迟；帧末结果相对输入帧末固定延后三拍。该流水把颜色判定、候选框更新和结果分类分开，降低像素流关键路径。

此实现不使用连通域标签、并查集或帧缓存。多个分离蓝色物体会合并为一个候选外接框；面积、最小宽高和二比一宽高比限制用于拒绝噪声和条状物体。

## 接口

| 端口 | 方向 | 说明 |
|---|---|---|
| `I_clk` | 输入 | 像素流时钟。 |
| `I_rst_n` | 输入 | 低有效异步复位。 |
| `I_tuser` | 输入 | 帧首有效拍。 |
| `I_tlast` | 输入 | 行末有效拍。 |
| `I_tvalid` | 输入 | 当前四像素字有效。 |
| `I_tdata[95:0]` | 输入 | 四个 RGB888 像素。 |
| `O_busy` | 输出 | 当前帧正在处理。 |
| `O_done` | 输出 | 帧末结果脉冲。 |
| `O_result_valid` | 输出 | 结果有效脉冲。 |
| `O_result_class[4:0]` | 输出 | `0` 未知、`1` 左、`2` 右。 |
| `O_result_ascii[7:0]` | 输出 | `?`、`L` 或 `R`。 |
| `O_frame_drop` | 输出 | 固定为低；此版本没有标签耗尽路径。 |

## 验证

`D:/anlu/rtl/sim/tb_traffic_sign_detector_96.sv` 覆盖左箭头、右箭头、无蓝色、红色物体、小面积噪声、宽扁候选和多蓝色区域场景。
