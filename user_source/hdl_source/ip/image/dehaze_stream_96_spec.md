# `dehaze_stream_96` 模块规格

## 目的

该模块为四像素 RGB888 流提供轻量化去雾，供 `isp_top` 的 `00` 模式使用。模块不保存整帧，适合 PH1P35 的片上 RAM 和固定速率视频链路。

## 算法

1. 每个四像素组先计算 `min(R,G,B)`，得到一个组暗通道值。
2. 两条组级行缓存先取垂直最小值，再与两个水平历史值取最小值，形成因果 3×3 暗通道窗口。图像上边界、左边界不使用不存在的邻居。
3. 固定大气光 `A=240`，使用 `t=1-0.85*dark/255` 的 Q0.8 近似，并将 `t` 限制到 `0.25` 以上。
4. 依据 `t` 分成六档增益（1.0、1.0625、1.25、1.5、1.75、2.0），用移位加法近似 `J=A+(I-A)/t`，避免逐像素除法。
5. 结果限制在 0～255。`I_enable=0` 时数据、标志和吞吐保持旁路。

组级暗通道会牺牲少量局部精度，但每拍仍处理 4 个像素，资源和时序开销明显低于逐像素 3×3 窗口；该模式输出同时进入灰度旁路，因此 CNN 采样器和 HDMI 预览使用同一份去雾数据。

## 接口与时序

- 输入和输出均为 96 位四像素 RGB888 固定速率流。
- `I_tuser`、`I_tlast`、`I_tvalid` 随数据经过 S0～S10 共 11 级寄存器。输入在边沿 n 被采样，输出在边沿 n+10 更新；仍支持每拍四像素。
- `I_enable` 在帧首有效拍锁存，帧内改变不会改变当前帧算法。
- 两个 `GROUP_WIDTH` 深度的 8 位数组用于行缓存，不需要 DDR 或完整帧缓存。
- 增益对无符号差值幅度做移位，再恢复符号；Python 模型使用相同舍入规则。

## 参数

| 参数 | 默认值 | 说明 |
|---|---:|---|
| `IMG_WIDTH` | 1280 | 图像宽度，必须是 4 的整数倍 |
| `IMG_HEIGHT` | 720 | 图像高度 |
| `ATMOSPHERIC_LIGHT` | 240 | 固定大气光 A |
| `OMEGA_Q8` | 218 | 去雾权重，约 0.85 |
| `MIN_TRANSMISSION` | 64 | 最小透射率，约 0.25 |
