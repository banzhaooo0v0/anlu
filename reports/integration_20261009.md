## TD 构建过程与最终状态

TD 实际版本：**6.2.168116**。脚本先导入器件数据库，再打开工程，避免加密 IP 在未初始化器件时展开失败。当前工程分析包含 **108 个源文件**。

本次 720p 的第一个完整综合通过，但物理实现因 **114/108 eRAM** 失败。按真实行宽缩减去马赛克缓存后，eRAM 降至 **105/108**；第二轮物理实现仍因 **21492/21216 slice** 失败。此后修改 CNN 列累加缓存存储方式、压缩有效位宽，并为 Logo 查表增加地址寄存级。以上中间版本均不作为交付 bitstream。

[首轮综合/实现日志](td_verify_20261009_150016.log)、[RAM 缩容轮日志](td_verify_20261009_150751.log)。旧 1024×600 整合尝试出现过 TD Optimize Design 内部崩溃；当前 720p 已完成过综合，不能把之前崩溃当作最终构建状态，也不将根因归于未经证明的单一代码修改。

第三轮综合估算为 20822/21216 slice、105/108 eRAM、34/40 DSP，布局实际 slice 为 20858/21216。该轮剩余 setup 路径为 `u_mode_selector/O_mode_reg` → `u_hdmi_mixer/mode_sync1_reg`，24 MHz 与 75 MHz 相关时钟之间只有约 0.653 ns 的建立窗口。已主动停止该轮未完成的布线，保留 [诊断日志](td_720p_mode_cdc_before_route_20261009.log)。

最终顶层使 OSD 读取 **ISP 使用的摄像头域模式 `S_algo_mode_sync_2`**，HDMI 模块继续进行双级接收同步及帧首锁存。摄像头域和 HDMI 域本来就在独立异步时钟组内；本次没有增加 false path 或更改时钟分组。此连接也使显示模式标签与 ISP 配置来自同一信号。

最终源码于 `20261009_153827` 综合通过：Setup WNS **+0.860 ns**、Hold WNS **+0.114 ns**、TNS 均为 0；估算 slice **20779/21216**、eRAM **105/108**、DSP **34/40**。随后完成布局，但自动线程的详细布线在 `Generate nets` 内部崩溃，产生 `minidump-20261009-154650.dmp`。[完整运行日志](td_verify_20261009_153827.log)、[物理实现失败日志](td_phy_1_20261009_153827.log)、[综合时序](td_gate_20261009_153827.timing)。综合时序不能替代最终布线时序。

从同一 `camera_to_dsi_display_place.db` 恢复，只设置 `flow thread 1`，未改 RTL/IP/约束。单线程运行越过原崩溃位置，记录见 [恢复日志](td_route_resume_single_20261009.log)。工程物理策略与构建脚本已固定单线程，并保留 [恢复 Tcl](../scripts/resume_td_route.tcl)；线程参数已由 TD 接受并持久化到工程。该措施是本次工具崩溃的规避方式，不将崩溃根因断言为已证明的线程竞态。

## 验证边界

- 上表方向图为合成激励，不代表真实赛道准确率。未做镜头、光照、运动模糊、远距离和多个蓝色目标的实测统计。
- CNN 只验证本次改动的 720p 输入采样与 bank 握手；未重新训练网络或测量全网络识别率。车控结果来自独立方向检测器。
- CNN RAM 使用 `CNN_SIM`；AWB/去马赛克容量检查使用明确的行为 RAM。去马赛克基线只为测试把未使用的 B 写口固定为 0，并保留原控制器。这些检查不能替代厂商加密原语时序仿真。
- 图像集成测试从 AWB RGB 之后开始，使用实际项目 FIFO RTL，但不包含传感器、MIPI PHY、DDR PHY 和实际显示器；空拍和背压为测试激励。
- TD 综合、布局布线与 XSim 功能仿真分别记录，不混称为“TD 完整系统仿真”。10 月 8 日 bitstream、时序与资源均属旧版本。
- 本机没有可用 ARMCC 5，STM32 随包构建结果来自队友。`scripts/verify_stm32_delivery.py` 不依赖队友电脑的原始目录；上游 `stm32/verify_package.py` 依赖该目录，未作为本机验证入口。
- 未连接开发板；未烧写 FPGA/STM32，未操作真实车辆。

仿真过程中 XSim 2019.2 对部分测试平台内的循环变量切片出现展开异常/内存增长；已将激励写成任务及普通整数表达式，并对 RAM/原生流测试关闭展开优化。生产 RTL 未为仿真器问题删除功能。所有表内 PASS 均来自修正后实际仿真日志。

源码、IP 与工程配置树 SHA-256 见 [清单](integration_source_sha256_20261009.json)，包含为兼容性保留的未使用旧模块；实际参与综合的文件以 TD 分析日志与工程列表为准。
